# Introducción a NumPy y Pandas

**NumPy** y **Pandas** son las librerías principales de Python para trabajar con datos. **NumPy** sirve para cálculos numéricos rápidos con arreglos de números. **Pandas** usa a NumPy para crear tablas de datos con nombres en las filas y columnas.
